# xcode 테스트 계획서

- 문서 버전: v1.0-pi
- 작성일: 2026-07-25
- 기반 모델: **pi-coding-agent** — event-driven agent loop, JSONL session tree, 4-package monorepo

---

## 1. 테스트 전략

| 레벨 | 도구 | 목적 | 대상 패키지 |
|---|---|---|---|
| 단위 테스트 | Jest / Vitest | provider event 변환, tool parse, compaction unit | `@xcode/ai`, `@xcode/agent-core`, `@xcode/coding-agent` |
| 통합 테스트 | Node.js integration test | agent loop + session tree + tools End-to-End | `@xcode/agent-core` + `@xcode/coding-agent` |
| Agent 시뮬레이션 | custom harness mock | event sequence, compaction trigger, retry/escalation | `@xcode/agent-core` |
| E2E | Playwright | IDE UI 흐름 | `@xcode/tui` |
| 성능 | custom benchmark | compaction latency, token budget 준수, IDE 응답 | `@xcode/agent-core`, `@xcode/tui` |
| 보안 | `gitleaks`, custom scan | secret 노출, project trust 강제, extension sandbox | 전체 |

## 3. 주요 테스트 시나리오

### 3.1 @xcode/ai

| ID | 시나리오 | 기대 결과 |
|---|---|---|
| AI-001 | OpenAI Responses API 호출 | 표준 event stream 생성 |

| AI-003 | Event schema 직렬화 | `user`/`assistant`/`tool`/`system`/`summary` payload가 schema에 맞게 변환 |
| AI-004 | Streaming abort | 사용자가 stop 시 stream 안전 종료 |

### 3.2 @xcode/agent-core

| ID | 시나리오 | 기대 결과 |
|---|---|---|
| AG-001 | Agent loop 기본 흐름 | prompt → LLM → tool parse → tool exec → result append → repeat |
| AG-002 | JSONL session tree append-only | 모든 turn/event가 session 파일에 append 됨 |
| AG-003 | Session tree branching | branch 생성 시 parent/child 관계 유지 |
| AG-004 | Session tree fork/clone | fork/clone 후 독립 session 정상 동작 |
| AG-005 | Compaction dedup | 동일 tool 결과 반복 시 최신만 남고 이전은 참조 |
| AG-006 | Compaction reduce old | 오래된 tool 결과는 핵심만 남음 |
| AG-007 | Compaction semantic summary | goal/decisions/files/failures/next 구조화 요약 |
| AG-008 | Compaction hard cap | context 한도 초과 시 강제 truncation 후 재개 |
| AG-009 | Tool registry 등록/실행 | built-in tool 정상 등록 및 실행 |
| AG-010 | Tool execution mode | sync/async 결과가 session에 기록 |
| AG-011 | Project trust 승인 | `.xcode/` 리소스는 승인 후 로드 |
| AG-012 | Project trust 거부 | 미승인 시 리소스 로드 차단 |
| AG-013 | Stop/Resume | 세션 중단 후 context 복원 및 재개 |
| AG-014 | Audit log | 모든 tool call/event 기록 |

| CA-006 | Planner plan 생성 | codebase 탐색 후 checkbox 기반 plan 생성 |
| CA-007 | Simple classify | 단순/복잡/위험 분류 정확도 ≥ 80% |
| CA-008 | Basic verify | test 통과 시 task 완료, 실패 시 retry |
