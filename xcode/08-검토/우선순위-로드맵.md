- 문서 버전: v1.0-pi
- 작성일: 2026-07-25

## 1. Phase 1 (MVP, 3~4개월)

> Phase 1 MVP 범위 확정서(`Phase1-MVP-범위확정서.md`) 참고.

### 1.1 P0 — core packages 완성

| 패키지 | 항목 | 목표 |
|---|---|---|
| **@xcode/ai** | Provider abstraction | OpenAI Responses-style API + Ollama(local) fallback |
| **@xcode/ai** | Event schema | `user`/`assistant`/`tool`/`system`/`summary` payload 표준화 |
| **@xcode/agent-core** | Agent loop | prompt → LLM → tool parse → tool exec → result append → repeat |
| **@xcode/agent-core** | JSONL Session Tree | append-only session + branching/fork/clone |
| **@xcode/agent-core** | CompactionEngine | dedup → reduce old → semantic summary → hard cap |
| **@xcode/agent-core** | Tool registry | built-in tool 등록/조회/실행 인터페이스 |
| **@xcode/agent-core** | Project Trust | `.xcode/` 리소스 로드 전 사용자 승인 |
| **@xcode/coding-agent** | Built-in tools | `read`, `edit`, `write`, `bash`, `test` |
| **@xcode/coding-agent** | Planner | codebase 탐색 후 task plan 생성 |
| **@xcode/coding-agent** | Simple classify | task를 단순/복잡/위험으로 분류 |
| **@xcode/coding-agent** | Basic verify | test 실행 결과(pass/fail) 기반 검증 |
| **@xcode/tui** | IDE skeleton | Tauri + Monaco editor + 채팅/계획/진행 UI |
| **@xcode/tui** | Interactive mode | 실시간 채팅 루프 |
| **@xcode/tui** | Print/JSON mode | one-shot 실행 및 자동화 지원 |

### 1.2 P1 — robustness & UX

| 패키지 | 항목 | 목표 |
|---|---|---|
| **@xcode/agent-core** | Working Memory | 현재 task의 goal/decisions/files/failures/next 구조화 유지 |
| **@xcode/agent-core** | Stop/Resume | 세션 중단 후 compaction/재개 |
| **@xcode/agent-core** | Audit log | agent 행동 기록 |
| **@xcode/coding-agent** | Secret scrubber | 로그에서 API 키/토큰 자동 마스킹 |
| **@xcode/coding-agent** | Context file loader | `AGENTS.md`/`CLAUDE.md` 자동 로드 |
| **@xcode/tui** | Permission gate UI | 파일시스템/shell 접근 시 사용자 동의 |
| **@xcode/tui** | Plan review UI | 생성된 plan 사용자 검토/승인 |

## 5. 기술 부채/개선 여지

- In-process handoff → message queue 확장.
- SQLite → PostgreSQL 마이그레이션 가이드.
- Compaction 요약 품질 평가 자동화.
- Marketplace 보안 강화 (code signing + sandbox).
- Extension supply-chain 강화 (`--ignore-scripts`, pinned refs, shrinkwrap, audit).
