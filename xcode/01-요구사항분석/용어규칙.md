# xcode 용어 규칙

- 문서 버전: v0.1
- 작성일: 2026-07-25

---

## 핵심 용어

| 용어 | 영문 | 정의 |
|---|---|---|
| 하네스 | Harness | AI 에이전트가 끝까지 일하게 만드는 런타임 + 제어 구조 |
| 루프 엔지니어링 | Loop Engineering | 에이전트에게 역할과 도구를 주고, 결과를 확인하며 끝날 때까지 반복하게 만드는 설계 |
| 그래프 엔지니어링 | Graph Engineering | 여러 에이전트/노드를 연결하고, 검증 실패 시 되돌리는 Dynamic Workflow 설계 |
| 컴팩션 | Compaction | 긴 context에서 필요한 기억만 남기고 나머지를 줄이는 다층 전략 |
| 워킹 메모리 | Working Memory | 현재 task에 필요한 정보를 담은 짧은 기억 |
| 작업 기억 | Task Memory | 특정 task의 목표, 결정, 실패, 다음 단계를 구조화한 기록 |
| 프로젝트 메모리 | Project Memory | `AGENTS.md` 형태의 코드베이스 지식 베이스 |
| 핸드오프 | Handoff | 에이전트 간 작업을 넘기는 메커니즘 |
| 볼더 | Boulder | LazyZ에서 사용하는 작업 진행 상태 객체 (checkbox progress) |
| 스킬 | Skill | 재사용 가능한 agent capability (e.g. `programming`, `review-work`) |
| 에스컬레이션 | Escalation | agent가 스스로 해결하지 못할 때 사용자에게 넘기는 것 |
| 게이트 | Gate | 작업이 다음 단계로 넘어가기 전 통과해야 하는 검증 |
| 폴리백 | Fallback | 주요 기능 실패 시 대체 동작 |
| 다층 캐시 | Tiered Cache | L1 메모리 → L2 Redis/로컬 → L3 DB 순으로 찾는 캐시 |
| 세션 트리 | Session Tree | JSONL 기반 append-only 세션 + branching 구조 |
| 브랜칭 | Branching | 세션 내 임의 지점에서 작업을 분기하는 것 |
| 스티어링 | Steering | agent tool 실행 중 전달되는 사용자 메시지 |
| 팔로우업 | Follow-up | agent가 모든 작업을 마친 후 전달되는 사용자 메시지 |
| 프로젝트 트러스트 | Project Trust | project-local 리소스 로드 전 사용자 승인 |
| 프롬프트 템플릿 | Prompt Template | `/templatename`으로 확장되는 reusable prompt |
| 익스텐션 | Extension | custom tool/command/UI/event를 등록하는 TypeScript 모듈 |
| 파이 패키지 | Pi Package | extension/skill/prompt/theme을 bundle한 npm/git 패키지 |
| 오프라인 모드 | Offline Mode | startup network 작업을 비활성화하는 모드 |
| 프린트 모드 | Print Mode | one-shot non-interactive 실행 모드 |

## 표기 원칙

- 영문 용어는 첫 등록 시 괄호로 병기.
- 파일/모듈명은 `PascalCase` 또는 `snake_case`로 통일.
- agent 이름은 `PlannerAgent`, `ExecutorAgent` 등 Role + Agent 형식.
