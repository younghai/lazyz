## 2. AI 정책

- 사용자는 자신의 API 키를 등록할 수 있다.
- 기본 제공 키가 있는 경우에도 요청당/월 토큰 한도를 적용한다.
- 로컬 모델 사용 시 모든 추론은 사용자 머신에서 실행된다.
- AI 생성 코드는 사용자의 책임 하에 사용되며, 라이선스 위반 가능성을 리뷰 agent가 경고한다.

---

## 3. 보안/개인정보

- 모든 secret(API 키, 토큰)은 OS credential store 또는 encrypted SQLite에 저장.
- agent 실행 로그에는 소스코드 일부가 포함될 수 있으므로, 민감 정보는 자동 마스킹.
- 원격 분석은 opt-in(기본 OFF). `XCODE_TELEMETRY=0`으로 언제든지 opt-out.
- **Project Trust**: `.xcode/`의 project-local extension/skill/prompt는 사용자 승인 후 로드.
- **Extension Sandbox**: marketplace/package의 extension은 filesystem/network 접근 권한 기반.
- **Package Security**: package 설치 시 `--ignore-scripts` 기본, pinned version/tag/commit 권장, code signing 단계별 도입.
- **Containerization**: 강한 격리가 필요하면 Gondolin extension, Plain Docker, OpenShell 중 하나를 권장. 기본 실행은 사용자 권한.
