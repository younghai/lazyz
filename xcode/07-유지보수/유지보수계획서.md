---

## 1. 데이터 보존

| 데이터 | 보존 기간 | 폐기 방식 |
|---|---|---|
| Session JSONL (원본) | 영구 (사용자 설정 가능) | 사용자가 삭제 시 제거 |
| 실행 로그 (RunLog) | 90일 | 자동 삭제 |
| Evidence 파일 | 30일 | 용량 초과 시 tail truncate |
| Working Memory | task 완료 후 7일 | 자동 삭제 |
| Project Memory | 영구 | 사용자가 삭제 시 제거 |
| Installed packages | 영구 | `xcode remove`로 제거 |

## 3. 의존성 관리

- `pnpm-lock.yaml`, `package-lock.json` 유지.
- 외부 의존성은 pinned.
- lifecycle script 포함 의존성은 보안 리뷰 후 allowlist 등록.
- extension/package는 Project Trust + code signing 검증.
