# xcode 장애 대응 런북

- 문서 버전: v1.0-pi
- 작성일: 2026-07-25
- 기반 모델: **pi-coding-agent** — 4-package monorepo, JSONL session tree

---

## 1. Agent loop 무한 반복

**증상**: agent가 같은 단계를 반복하며 끝나지 않음.

**진단**:
- `@xcode/agent-core`에서 `cycle_count`, `fail_count` 확인.
- 최근 5개 log event 비교.

**복구**:
1. 자동으로 `MAX_CYCLES` 도달 시 `failed` 상태로 전환.
2. 사용자에게 escalation.
3. 필요 시 task 중지 후 재시작.

---

## 2. LLM provider 장애

**증상**: 모든 요청에서 timeout 또는 5xx.

**진단**:
- `@xcode/ai` provider health check.
- provider별 error rate.

**복구**:
1. secondary provider로 fallback.
2. local model이 설정되어 있으면 local로 전환.
3. 모두 실패 시 human escalation.

---

## 3. Context 한도 초과로 작업 중단

**증상**: compaction 후에도 context가 넘어 agent가 멈춤.

**진단**:
- `@xcode/agent-core` compaction pipeline 각 단계 출력 크기 확인.
- hard cap 설정값 확인.

**복구**:
1. 가장 큰 tool result부터 강제 자르기.
2. 사용자에게 핵심 정보 요약 제공.
3. 필요 시 task를 더 작은 subtask로 분할.

---

## 4. Secret 유출 의심

**증상**: 로그에 API 키/토큰 노출.

**진단**:
- `@xcode/coding-agent` SecretScrubber 동작 여부 확인.
- 마스킹 규칙 업데이트 필요 여부 확인.

**복구**:
1. 즉시 노출된 키 폐기/재발급.
2. scrubber 규칙 강화.
3. audit log로 영향 범위 파악.

## 5. Session JSONL 손상

**증상**: `/tree`, `/resume` 시 세션 파일 파싱 실패.

**진단**:
- 파일 끝에 불완전한 JSONL 라인이 있는지 확인.
- 백업 파일 존재 여부 확인.

**복구**:
1. 마지막 완전한 라인까지 truncate.
2. 백업에서 복원.
3. checksum 검증 추가.

## 6. Extension Crash

**증상**: extension 로드 후 xcode가 비정상 종료.

**진단**:
- `--no-extensions`로 시작해 `@xcode/agent-core` 동작 확인.
- `.xcode/extensions/` 또는 installed package 하나씩 disable.

**복구**:
1. 문제 extension 식별.
2. `--exclude-tools` 또는 `xcode remove`로 제거.
3. Project Trust 재검토.

## 7. Package Install Failure / Supply-chain

**증상**: `xcode install` 실패 또는 설치 후 이상 동작.

**진단**:
- `--ignore-scripts` 적용 여부 확인.
- package ref가 pinned인지 확인.
- `npm audit` 결과 확인.

**복구**:
1. pinned version으로 재설치.
2. 의심 package 제거.
3. `XCODE_OFFLINE=1` 모드로 offline 작업.

## 8. IDE UI 멈춤

**증상**: `@xcode/tui` 화면이 응답하지 않음.

**진단**:
- agent loop가 blocking 상태인지 확인.
- Tauri main process CPU/memory 확인.

**복구**:
1. agent loop pause.
2. UI reload.
3. 필요 시 `--no-extensions`로 재시작.
