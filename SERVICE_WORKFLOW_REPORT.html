1. Executive Summary

LazyZ는 OmO / LazyCodex agent harness의 ZCode 배포판입니다. 프로젝트 메모리 생성, 의사결정이 완전한 계획 수립, 지속 가능한 실행, 검증된 완료를 하나의 설치 가능한 ZCode 플러그인으로 패키징합니다.

Typical workflow: 
/init-deep → /ulw-plan "feature" → approve plan → /start-work → review → done

실제 처리는 스킬 레이어, 수명주기 훅 레이어, 그리고 소수의 로컬/원격 MCP 도구가 담당합니다.

Skill triggering mechanisms

  1. Command wrappers explicitly name a skill (e.g., /ulw-plan → ulw-plan).
  2. ZCode auto-loads skills whose description frontmatter matches the prompt.
  3. Hooks inject skill directives:
    • ultrawork UserPromptSubmit hook injects the ultrawork directive when the prompt contains “ultrawork” / “ulw”.
    • ulw-loop UserPromptSubmit hook steers loop goals.
    • rules SessionStart/UserPromptSubmit hooks inject project rules.
  4. Post-tool hooks surface feedback that loads comment-checker, lsp, or rules guidance after edits.

빌드 시 sync-skills.mjs는 ZCode 전용 “Harness Tool Compatibility” 블록을 삽입하여 upstream call_omo_agent / task / spawn_agent 예시를 ZCode의 기본 Agent 도구에 매핑합니다.

Continuation mechanism

모델 턴이 종료되면 start-work-continuation Stop 훅이 .omo/boulder.json을 검사합니다. 확인되지 않은 작업이 남아 있으면 decision: block과 연속 지시문을 반환합니다. 이를 통해 수 시간에 걸친 계획도 수동 재시작 없이 여러 ZCode 턴에 걸쳐 진행할 수 있습니다. 세션당 기본 상한은 DEFAULT_MAX_CONTINUATIONS = 10이며, LAZYZ_START_WORK_MAX_CONTINUATIONS로 재정의할 수 있습니다.

8. Build & Deployment Workflow

End-user installation

빌드가 필요 없습니다. 모든 훅과 로컬 MCP 서버에 대해 사전 빌드된 dist/가 포함되어 제공됩니다.

zcode plugin marketplace add https://github.com/code-yeongyu/lazyz
zcode plugin add lazyz@lazyz

요구사항:

  • macOS 또는 Linux용 ZCode(이번 릴리스에서는 Windows를 지원하지 않음).
  • PATH에 Node.js 20+.

Build from source

cd plugins/lazyz
npm install
npm run build

Node.js 20+ 외에 Bun이 필요합니다.

Build pipeline

Hook launcher diagnostics

scripts/run-hook.sh는 훅을 실행하기 전에 Node.js와 dist/cli.js의 존재를 확인합니다. 무언가 누락되면 세션을 실패시키지 않고 stderr에 진단 메시지를 출력합니다.

Opt-out controls

첫 실행 전:

touch ~/.omo/telemetry-disabled

또는 환경 변수를 통해:

export OMO_CODEX_DISABLE_POSTHOG=1
export OMO_CODEX_SEND_ANONYMOUS_TELEMETRY=0
# Global variants also accepted:
export OMO_DISABLE_POSTHOG=1
export OMO_SEND_ANONYMOUS_TELEMETRY=0

옵트아웃되면 telemetry 컴포넌트는 no-op PostHog 클라이언트를 생성하고 네트워크 호출을 하지 않습니다.

Product events

최상위 README.md는 옵트인, 로컬 전용 product-events 모드(LAZYZ_PRODUCT_EVENTS=1 / OMO_PRODUCT_EVENTS=1)를 문서화하고 있으며, plan_start, work_complete, resume_prompted, init_deep_suggested, build_missing 같은 이벤트를 ~/.lazyz/product-events.jsonl에 기록합니다.

Status: 해당 기능은 코드베이스에 아직 구현되어 있지 않습니다. plugins/lazyz/docs/known-limitations.md는 “Telemetry is DAU-only … Tracked for Sprint 2: opt-in (default OFF) product events.”라고 명시합니다.
